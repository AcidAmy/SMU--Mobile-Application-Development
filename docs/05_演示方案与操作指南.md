# 第五章：演示方案与操作指南

---

## 5.1 演示目标与设计原则

本演示专为**课程大作业提交、技术答辩、学术分享或组内分享**量身定制。演示的核心目标是：
1. **真实性**：使用包含复杂排版（多级标题、嵌套表格、学术引用、富文本网页）的真实样本；
2. **直观性**：现场对比转换前的源文件与转换后的 `.md` 文本；
3. **高效性**：一键脚本自动化执行，全程无卡顿，1 秒内完成多格式全流程解析。

---

## 5.2 演示素材文件清单

在项目的 `demo/samples/` 目录中已准备好以下典型测试样本：

| 样本文件 | 格式 | 包含的复杂要素 | 演示看点 |
| :--- | :--- | :--- | :--- |
| **`document.docx`** | Word 文档 | 论文标题、摘要、段落、正规 6 列数据表格、图片 | 观察表格是否保持 Markdown 语法，标题是否被正确识别为 `#` |
| **`financial_table.xlsx`** | Excel 表格 | 多个 Sheet 工作表、数值矩阵、列名定义 | 观察是否自动按 Sheet 分块并输出规范的 Markdown 对齐表格 |
| **`research_paper.pdf`** | PDF 文档 | 多栏文本排版、学术引用序号、长篇英文段落 | 观察分词连续性与换行符清洗效果 |
| **`web_article.html`** | HTML 网页 | 导航栏、外链超链接、多级标题、嵌套列表 | 观察 HTML 杂乱标签是否被剔除，超链接语法 `[text](url)` 是否完整 |

## 5.3 现场演示操作步骤（极简 3 步法）

### 步骤 1：打开终端并进入项目目录
```bash
cd /Users/Aridmitten/Documents/markitdown
```

### 步骤 2：启动一键演示脚本
直接运行已准备好的一键演示工具：
```bash
./demo/quick_start.sh
```
或者显式激活环境运行：
```bash
source .venv/bin/activate
python3 demo/run_demo.py
```

### 步骤 3：观察控制台高亮输出与结果对比
控制台将输出清晰的彩色流转步骤：
1. 显示 Python 3.12 与 MarkItDown 0.1.8 引擎版本；
2. 逐一展示 4 种文件格式的转换耗时（通常均在 0.05s ~ 0.4s 之间）；
3. 打印统计报表（总耗时约 0.7 秒，共生成上百行标准 Markdown）；
4. 输出各格式转换后的前 6 行精选内容预览。

## 5.4 现场互动/即兴命令演示（展示深厚功底）

若评委或老师现场提出指定转换或临时抽取文件，可现场展示 CLI 命令行：

```bash
# 1. 现场命令行极速转换单文件并查看
.venv/bin/markitdown demo/samples/document.docx | head -n 25

# 2. 现场展示 Linux 经典管道能力
cat demo/samples/financial_table.xlsx | .venv/bin/markitdown -x .xlsx
```
这一操作能展现对 Unix 管道理念与软件底层 I/O 的深刻理解。
