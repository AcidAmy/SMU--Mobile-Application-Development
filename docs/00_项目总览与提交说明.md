## 📌 项目元数据 (Project Metadata)

- **项目名称**：Microsoft MarkItDown (开源文档转 Markdown 工具库)
- **开源组织**：Microsoft
- **官方仓库**：[microsoft/markitdown](https://github.com/microsoft/markitdown)
- **语言与技术栈**：Python 3.12、Hatchling、Magika (AI 文件格式嗅探)、Pdfminer/Pdfplumber、Mammoth、OpenPyXL
- **文档构建日期**：2026年10月
- **适用场景**：大语言模型数据预处理、RAG (检索增强生成) 知识库解析、多模态文档结构化清洗
