# 第三章：安装部署与环境配置手册

---

## 3.1 运行环境要求

根据项目根目录 `pyproject.toml` 官方规范：
- **操作系统**：macOS (x86_64 / arm64 Apple Silicon)、Ubuntu / Debian Linux、Windows 10/11
- **Python 版本**：**`>= 3.10, < 3.15`**（生产与教学推荐使用 **Python 3.12**）
- **核心构建工具**：`hatchling` (PEP 517 / PEP 660 构建后端)

---

## 3.2 完整安装步骤（以 macOS 为例）

### 步骤 1：安装 Python 3.12
1. 前往 Python 官网下载 macOS 安装包并安装：
   - 官方地址：https://www.python.org/downloads/macos/
2. 验证系统环境：
   ```bash
   python3.12 --version
   # 预期输出: Python 3.12.x
   ```

### 步骤 2：创建隔离虚拟环境
为防止与系统全局包冲突，推荐在项目根目录下创建独立虚拟环境：
```bash
cd /Users/Aridmitten/Documents/markitdown

# 1. 创建虚拟环境
python3.12 -m venv .venv

# 2. 激活虚拟环境
source .venv/bin/activate
```

### 步骤 3：配置 SSL 根证书（macOS 避坑必读）
macOS 官方 Python 安装包默认不继承系统钥匙串中的根证书，直接执行 pip 会提示 `SSLCertVerificationError`。
通过以下命令完成根证书关联：
```bash
# 安装 certifi 证书包
python3.12 -m pip install certifi

# 将证书环境变量写入虚拟环境激活脚本
CERT_PATH=$(python3.12 -c "import certifi; print(certifi.where())")
echo "export SSL_CERT_FILE=\"$CERT_PATH\"" >> .venv/bin/activate

# 重新激活生效
source .venv/bin/activate
```

### 步骤 4：安装 MarkItDown 与全部依赖全家桶
```bash
# 安装构建依赖
pip install hatchling

# 优先安装预编译二进制 wheel，避免源码编译 OpenSSL/Rust
pip install --prefer-binary -e 'markitdown-main/packages/markitdown[all]'
```

## 3.3 可选格式扩展包对应表

若在资源受限环境（如嵌入式设备或轻量容器）中，可按需精简安装：

| 扩展名标识 | 对应格式支持 | 引入的关键底层库 |
| :--- | :--- | :--- |
| `markitdown[docx]` | Word `.docx` 格式 | `mammoth`, `lxml` |
| `markitdown[xlsx]` | Excel `.xlsx` 格式 | `pandas`, `openpyxl` |
| `markitdown[pdf]` | PDF 文档格式 | `pdfminer.six`, `pdfplumber`, `pypdfium2` |
| `markitdown[pptx]` | PowerPoint 幻灯片 | `python-pptx` |
| `markitdown[audio-transcription]` | 音频转录 (WAV/MP3) | `pydub`, `SpeechRecognition` |
| `markitdown[all]` | **全功能支持（推荐）** | 安装上述全部依赖 |

## 3.4 环境就绪验证检查表

在终端依次运行以下自检指令：

```bash
# 1. 验证 CLI 命令可用性
markitdown --help

# 2. 验证 Python API 导入
python -c "import markitdown; print('MarkItDown Version:', markitdown.__version__)"

# 3. 运行自动化演示测试
./demo/quick_start.sh
```

若全部返回正常且无报错，则代表运行环境已完全部署成功！
