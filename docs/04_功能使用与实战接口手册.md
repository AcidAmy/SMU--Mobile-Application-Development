## 4.1 CLI 命令行工具实战指南

安装完成后，系统自动注册 `markitdown` 全局命令行工具。

### 1. 基础单文件转换
```bash
# 将 Word 文档转为 Markdown 并直接输出到终端
markitdown my_document.docx

# 使用 -o 参数将结果保存到指定文件
markitdown financial_report.xlsx -o report.md

# 转换 PDF 文件并重定向标准输出
markitdown paper.pdf > paper.md
```

### 2. Linux 管道流式处理（Unix Philosophy）
MarkItDown 原生支持标准输入流（stdin）管道处理：
```bash
# 从网络下载并直接流式转为 Markdown
curl -sSL https://example.com/sample.pdf | markitdown -x .pdf > sample.md

# 配合 cat 命令
cat data.csv | markitdown -x .csv > output.md
```

### 3. 插件管理命令
```bash
# 列出当前系统中已安装的第三方扩展插件
markitdown --list-plugins

# 启用插件运行转换
markitdown --use-plugins scanned_doc.pdf -o output.md
```

## 4.2 Python SDK 编程接口开发范例

### 范例 1：最简基础调用
```python
from markitdown import MarkItDown

# 1. 实例化转换器引擎
md = MarkItDown()

# 2. 执行转换
result = md.convert("demo/samples/financial_table.xlsx")

# 3. 获取并打印输出结果
print(result.markdown)
```

### 范例 2：流式与受限只读转换（生产安全推荐）
在面向 Web 服务后端时，建议调用受限只读方法防止路径穿越：
```python
from pathlib import Path
from markitdown import MarkItDown

md = MarkItDown()

# 仅允许读取本地受信任文件
result = md.convert_local(Path("demo/samples/document.docx"))

# 或者从内存 BytesIO 中转换
with open("demo/samples/research_paper.pdf", "rb") as f:
    result = md.convert_stream(f, file_extension=".pdf")
    print(result.markdown[:200])
```

### 范例 3：批量文件夹转换流水线（RAG 知识库预处理）
```python
import os
from pathlib import Path
from markitdown import MarkItDown

def batch_convert_directory(input_dir: str, output_dir: str):
    """批量将输入目录下所有支持的文档转换为 Markdown"""
    md = MarkItDown()
    in_path = Path(input_dir)
    out_path = Path(output_dir)
    out_path.mkdir(parents=True, exist_ok=True)

    supported_exts = {".docx", ".pdf", ".xlsx", ".pptx", ".html", ".csv", ".json"}

    for file_path in in_path.rglob("*"):
        if file_path.suffix.lower() in supported_exts:
            try:
                print(f"正在处理: {file_path.name}")
                res = md.convert(str(file_path))
                
                target_file = out_path / f"{file_path.stem}.md"
                target_file.write_text(res.markdown, encoding="utf-8")
                print(f"  ✓ 成功生成: {target_file.name}")
            except Exception as e:
                print(f"  ✗ 转换失败 [{file_path.name}]: {e}")

if __name__ == "__main__":
    batch_convert_directory("demo/samples", "demo/output")
```

## 4.3 高级功能：对接云端多模态大模型

### 1. 接入 OpenAI 视觉模型实现图片描述与 OCR
```python
from markitdown import MarkItDown
from openai import OpenAI

# 传入 OpenAI 兼容客户端
client = OpenAI(api_key="your-api-key")
md = MarkItDown(
    llm_client=client,
    llm_model="gpt-4o",
    llm_prompt="详细提取图片中的表格、图表说明与文字内容"
)

res = md.convert("product_diagram.jpg")
print(res.markdown)
```

### 2. 接入 Azure Content Understanding 提取结构化 YAML 字段
```python
from markitdown import MarkItDown

# 配置 Azure 端点
md = MarkItDown(
    cu_endpoint="https://your-resource.cognitiveservices.azure.com/",
    cu_analyzer_id="prebuilt-documentSearch"
)

res = md.convert("contract_agreement.pdf")
# 输出结果顶部自带 YAML Front Matter 元数据
print(res.markdown)
```
